# Troubleshooting Guide 01: Connected to Wi-Fi but No Internet

## Issue
A user reports that their Windows computer is connected to Wi-Fi but cannot access websites or online services.

## Initial Questions
- Is the problem affecting one device or multiple devices?
- Does the Wi-Fi icon show that the computer is connected?
- Did the problem start recently?
- Are other websites or applications working?

## Troubleshooting Steps
1. Confirm that Wi-Fi is enabled and the correct network is selected.
2. Check whether other devices on the same network can access the internet.
3. Open another website to determine whether the issue affects one website or all websites.
4. Disconnect from Wi-Fi and reconnect.
5. Restart the browser and test again.
6. If permitted by organisational procedures, restart the computer and retest.
7. If the issue continues, record the error message and troubleshooting results.

## Expected Outcome
The user can access the internet, or the cause is identified for escalation.

## Resolution
Record the confirmed cause, action taken and result. Do not claim the issue is resolved until it has been tested.

## Escalation
Escalate if the issue persists, affects multiple users, involves network infrastructure or requires permissions beyond first-line support.

## Ticket Notes
Record the affected device, time reported, symptoms, tests performed, results, actions taken and escalation reference.

## Security Reminder
Never ask users to share passwords. Follow organisational security procedures and only perform authorised actions.
