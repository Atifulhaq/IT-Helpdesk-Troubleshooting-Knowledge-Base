# Troubleshooting Guide 02: Windows Login Problems

## Issue
A user cannot sign in to their Windows computer or receives an error when entering their credentials.

## Initial Questions
- What exact error message appears?
- Is this a personal or organisation-managed device?
- Did the user recently change their password?
- Can other users sign in to the same device?
- Is a network connection required for sign-in?

## Troubleshooting Steps
1. Check that the correct account or username is being used.
2. Check whether Caps Lock or the keyboard layout affects password entry.
3. Record the exact error message without recording the password.
4. If required, check the device's network connection.
5. Direct users who have forgotten their password to the approved reset process.
6. Follow organisational identity-verification procedures for locked or disabled accounts.
7. Retest access after an authorised corrective action.

## Expected Outcome
The user signs in successfully, or the cause is identified for escalation.

## Resolution
Document the confirmed cause, authorised action and result. Confirm that sign-in works before closing a real ticket.

## Escalation
Escalate account lockouts, disabled accounts, authentication-service failures or persistent login errors that exceed first-line permissions.

## Ticket Notes
Record the device, error message, time reported, checks performed, results and escalation details. Never include passwords or authentication codes.

## Security Reminder
Verify the user's identity according to organisational policy. Never bypass authentication controls or request a user's password.
