# Practice Helpdesk Ticket 003: Account Locked

## Ticket Information
- Ticket ID: HD-003
- Category: Account Access
- Priority: Medium (provisional)
- Status: Practice scenario
- Reported by: Example user
- System: Windows user account

## Reported Issue
The user reports that they cannot sign in because their account appears to be locked after several unsuccessful login attempts.

## Initial Assessment
The cause is not yet confirmed. Possible causes include repeated incorrect passwords, an outdated saved password on another device, or an account-security policy.

## Troubleshooting Steps
1. Ask the user for the exact error message and when the issue began.
2. Confirm whether the problem affects one user or multiple users.
3. Check that the correct username is being used.
4. Follow the organisation's approved identity-verification procedure.
5. Direct the user to the approved account-unlock or password-reset process.
6. If the issue persists, record the results and escalate to the authorised support team.

## Simulated Resolution
For this practice scenario, assume the user's identity was verified and the account was unlocked by an authorised support technician. The user then signed in successfully.

Note: This is an illustrative scenario, not a real incident or verified test result.

## User Confirmation
In a real ticket, confirm that the user can sign in successfully before closing the ticket.

## Escalation
Escalate if:
- The account remains locked after the approved recovery process.
- The account is disabled or requires administrator access.
- Multiple users experience similar login problems.
- There are signs of suspicious activity or possible account compromise.

## Security Considerations
- Never ask for or record the user's password.
- Never bypass identity-verification procedures.
- Do not unlock accounts unless authorised.
- Follow organisational security policies.

## Lessons Learned
- Gather the exact error message before diagnosing the issue.
- Verify identity before account changes.
- Document actions and results clearly.
- Escalate issues beyond first-line permissions.
