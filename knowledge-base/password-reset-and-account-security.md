# Knowledge Base: Password Reset and Account Security

## Purpose

This guide explains how first-line IT support can help users who have forgotten their password or are concerned about account security.

## Common Issues

- A user has forgotten their password.
- An account has been locked after repeated unsuccessful sign-in attempts.
- A user suspects someone else may know their password.
- A user cannot complete multi-factor authentication (MFA).

## Troubleshooting Procedure

### 1. Identify the Issue
- Ask the user what problem they are experiencing.
- Record any error message without collecting passwords or authentication codes.
- Establish whether the issue affects one account or multiple users.

### 2. Verify the User's Identity
- Follow the organisation's approved identity-verification procedure.
- Never bypass identity checks, even if the request appears urgent.

### 3. Follow the Approved Recovery Process
- Direct users to the organisation's official password-reset service.
- For locked or disabled accounts, follow the approved account-recovery process.
- Escalate issues that require administrator permissions or specialist support.

### 4. Check Account Security
- If a password may have been compromised, follow the organisation's security incident procedure.
- Advise the user to use a strong, unique password in accordance with organisational policy.
- Follow approved procedures for reviewing active sessions or resetting MFA where necessary.

### 5. Confirm the Outcome
- Ask the user to test sign-in.
- Confirm whether access has been restored.
- Record the steps taken and escalate if the issue remains unresolved.

## Security Rules

- Never ask a user to disclose their password.
- Never record passwords or MFA codes in a ticket.
- Never disable security controls to bypass a login problem.
- Only perform actions within your authorised permissions.
- Report suspected account compromise through the appropriate security channel.

## Escalation Criteria

Escalate when:
- The account may have been compromised.
- The approved recovery process fails.
- The account remains locked or disabled.
- MFA is not working and requires specialist intervention.
- The issue affects multiple users or may indicate a wider service outage.

## Ticket Documentation

Record:
- The reported problem and relevant error message.
- Identity-verification steps completed, without sensitive information.
- Troubleshooting actions and results.
- Whether access was restored.
- Any escalation reference.

## Key Learning

Effective first-line support combines structured troubleshooting, clear communication, accurate documentation and strong security practices.
