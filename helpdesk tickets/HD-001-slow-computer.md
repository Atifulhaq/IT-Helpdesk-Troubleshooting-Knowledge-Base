# Practice Helpdesk Ticket 001: Slow Computer

## Ticket Information
- Ticket ID: HD-001
- Category: Hardware / Performance
- Priority: Medium (provisional)
- Status: Practice scenario
- Reported by: Example user
- Device: Windows computer

## Reported Issue
The user reports that their computer starts slowly and applications take a long time to open.

## Initial Assessment
The cause is unknown. Possible causes include high resource usage, insufficient free storage, background applications or pending updates.

## Troubleshooting Steps
1. Ask when the problem started and whether all applications are affected.
2. Check Task Manager for unusually high CPU or memory usage.
3. Check available disk space.
4. Review unnecessary startup applications.
5. Check for pending updates or a required restart.
6. Record findings before taking corrective action.

## Simulated Resolution
For this practice scenario, assume an unnecessary application was identified as using excessive resources. After an authorised change and restart, performance improved.

Note: This is an illustrative scenario, not a real incident or verified test result.

## User Confirmation
In a real ticket, confirm that the computer works as expected before closing it.

## Escalation
Escalate if performance remains poor, hardware failure is suspected or administrator permissions are required.

## Lessons Learned
- Gather symptoms before assuming the cause.
- Use diagnostic tools to support decisions.
- Document actions and results.
- Confirm the outcome before closing a real ticket.
